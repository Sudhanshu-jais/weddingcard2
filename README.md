# Krishna & Himanshi — Hindi Wedding Invitation Website

A responsive, single-page Hindi wedding invitation website with a cinematic palace-and-lake theme.

## Run locally
1. Extract the project folder.
2. Keep `index.html` and the `assets/` folder together.
3. Open `index.html` in a modern browser.

An internet connection is recommended for the Google Fonts and Google Maps link. The page layout, scenic background, event imagery, countdown, navigation, and animations run locally.

## Included sections
- Cinematic palace-and-lake hero background with a live Hindi invitation and floating petal animation
- Couple introduction and wedding date
- Countdown to the wedding
- Quick links to events, venue, and contact
- Featured main wedding and blessing ceremony, followed by three pre-wedding event cards
- Venue details with Google Maps directions
- Bride and groom family details
- Contact numbers and closing message

## Notes
- Numbers use standard Arabic digits (123).
- The countdown targets 3 December 2026 at 7:00 PM India Standard Time.
- Please verify family details, contact numbers, venue address, and ceremony timings before publishing.
